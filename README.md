## 📖 Overview

Notes for Apple Watch is a standalone watchOS application developed with SwiftUI.

The project explores Apple's watchOS ecosystem and demonstrates how to build a functional notes application specifically designed for the Apple Watch experience.

Users can create notes, browse saved notes, view individual note details, adjust reading preferences, and manage their content directly from their wrist.

## ✨ Features

- 📝 Create and manage notes.
- 📋 Display notes in an organized list.
- 💾 Permanently save notes locally.
- 🔍 View individual note details.
- 🗑️ Delete notes using SwiftUI gestures.
- 🎙️ Voice dictation support.
- ✍️ Scribble, Emoji, and keyboard input.
- ⚙️ Adjustable line spacing with Slider.
- 🎨 Custom reusable SwiftUI components.
- 🧭 Navigation between multiple views.
- ⌚ Standalone Apple Watch experience.
