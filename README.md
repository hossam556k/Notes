# ⌚ Notes for Apple Watch

A modern, standalone Notes application built for **Apple Watch** using **SwiftUI** and **watchOS**. Create, manage, and save your notes directly on your wrist with a clean interface and a smooth native experience.

## ✨ Features

- 📝 Create and manage notes directly on Apple Watch.
- 💾 Persistent local data storage.
- 📋 Display notes in an organized list.
- 🔍 View individual note details.
- 🗑️ Delete notes using SwiftUI gestures.
- 🎙️ Voice dictation input.
- ✍️ Support for Scribble, Emoji, and keyboard input.
- 🎨 Custom SwiftUI components and reusable design language.
- ⚙️ Adjustable line spacing using SwiftUI Slider.
- 🧭 Smooth navigation between multiple views.
- 📱 Standalone watchOS application.

## 🛠 Tech Stack

| Technology | Purpose |
|---|---|

## 🚀 Getting Started

### Requirements

- macOS
- Xcode
- Swift
- Apple Watch Simulator or a compatible Apple Watch device.

### Installation

1. Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

2. Open the project in Xcode.

3. Select the Notes Watch target.

4. Choose an Apple Watch Simulator.

5. Build and run the application.

## 🎯 Project Purpose

The goal of this project was to explore the Apple Watch ecosystem and gain practical experience building standalone watchOS applications using SwiftUI, focusing on data management, user interaction, navigation, and native interface design.
